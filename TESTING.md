# Проверка Trajectory AI 1.3.6

## Изменения сборки

Удалены неиспользуемые варианты развёртывания, соответствующие файлы, внешняя отправка заданий, служебные HTTP-маршруты и драйвер другой базы. Приложение использует SQLite и встроенный обработчик очереди. Токены исполнения, отмена, повтор, проверяющий агент и контроль публикации сохранены. Формат сохранённых данных не менялся.

Обновлены README, техническое описание, памятка преподавателю и Word-инструкция. Новый порядок обновления заменяет подпапку исходников целиком и возвращает data, .venv и .env на прежние пути; .runtime остаётся на месте. Архив предназначен также для чистой установки преподавателем.

## Автоматические проверки этой версии

Полный набор выполнен в Python 3.12: **81 passed, 1 skipped**, одно предупреждение Starlette о будущем переходе TestClient на другой HTTP-клиент. Пропущена проверка личных вложений пользователя: они не входят в распространяемый архив.

Дополнительно запущен настоящий Uvicorn с включённой фоновой очередью в демонстрационном режиме. Через HTTP выполнены регистрация, создание плана и урока, отметка чтения, успешная попытка теста и проверка журнала. После остановки и повторного запуска сервера курс, завершённая тема и попытка сохранились. Это проверка сервера и очереди без обращения к реальной модели.

Синтаксис Python проверен разбором AST, JavaScript — node --check. В исходниках, именах файлов и XML содержимого Word не обнаружены удалённые технологии. Все 15 страниц Word-инструкции отрендерены и просмотрены.

Проверяются регистрация, сессии, CSRF, Origin, разграничение доступа, загрузка TXT/DOCX и отказ для скана; календарный бюджет, нехватка времени, смена уровня, сохранение прогресса и попыток; поиск источников и допустимость ссылок; цикл генерации с исправлением, лимит трёх версий, отмена, повторный claim и невозможность сохранения устаревшей задачи; адаптивный итоговый тест; подготовка окружения, проверка модели и состав ZIP. Сетевые адаптеры проверяются с подменёнными ответами.

В автоматических тестах демонстрационный генератор используется для воспроизводимых проверок логики. Они не доказывают качество конкретного ответа Qwen. Проверки адаптеров и запускатора с подменой ответов не являются настоящими запросами к модели.

## Ранее подтверждено на ноутбуке пользователя

Пользователь запускал локальную Qwen3 4B, получил двухтемный план по HTML/DOM и первый урок. Неверный и верный варианты теста дали 0 и 100, корректная HTML-страница получила AI-оценку 100, прогресс обновился до 50%. Эти наблюдения относятся к коду до текущей очистки и не выдаются за новый прогон на Windows.

При ручном просмотре обнаружены недостатки содержания: составной вопрос раскрыт не полностью, варианты «h1» и «<h1>» близки по смыслу, оценщик предложил часть лишних рекомендаций. Очистка сборки сама по себе эти проблемы генерации не исправляет. Итоговый тест на ноутбуке пользователя ещё не подтверждён до конца.

## Границы проверки

В этой среде не выполняется запуск Windows BAT/PowerShell на настоящем ноутбуке. Новые реальные ответы Qwen при этой очистке не запрашивались. Подробная инструкция проверяется рендерингом страниц Word; код сервера проверяется в Python 3.12. На компьютере преподавателя требуется завершить сценарий из PREPOD_START_HERE.txt, включая повторный запуск и сохранение курса.
