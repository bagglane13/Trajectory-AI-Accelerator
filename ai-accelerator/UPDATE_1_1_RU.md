# Обновление и исправление старых курсов

Текущий порядок установки и обновления с сохранением данных находится в [../UPDATE_1_3_6_RU.txt](../UPDATE_1_3_6_RU.txt). Используйте START.bat из общей папки проекта.

Уже сохранённая теория не переписывается после обновления кода. Для пересоздания неудачного курса откройте «Настройки» → «Создать исправленную копию курса». Проверьте извлечённые вопросы, затем постройте новый план. Исходный курс и попытки сохраняются; новая копия начинается без прогресса.

Изменение уровня и расписания сначала можно оценить через «Проверить, хватит ли времени». Для применения сохраните настройки. Пройденные темы и попытки сохраняются, уже подготовленная теория остаётся прежней. Нехватка времени при перепланировании не изменяет действующий план.
