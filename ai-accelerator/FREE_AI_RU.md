# Подключение бесплатной нейросети — версия 1.2

В сборке есть реальные адаптеры Gemini и локальной Ollama. Это подготовленная интеграция: без установки модели или вашего личного ключа генерация сама не включится. Чужие ключи в архив не вложены. Удалённого доступа к вашему компьютеру у автора изменений нет.

## Обновление именно вашего проекта

1. Остановите сервер через Ctrl+C в его окне.
2. Распакуйте весь архив в отдельную новую папку. Не запускайте файлы прямо из ZIP.
3. Запустите `INSTALL_UPDATE.bat` из корня распакованного архива.
4. Скрипт найдёт `C:\Users\Artem\!учеба\АОКГ ПРОЕКТ\v2\Trajectory_AI_Accelerator` или вложенную в неё `ai-accelerator`, обновит исходники и откроет мастер подключения. Предыдущие изменённые исходники сохраняются в `backup-code-...`; data, .env и .venv не заменяются.
5. Если папка не найдена, вручную скопируйте содержимое `ai-accelerator` из архива поверх своей папки, где находится start.bat, и запустите `connect-ai.bat` в этой папке. Сделайте копию проекта перед ручным обновлением. Не удаляйте data и .env.

## Вариант 1: Ollama — без ключа и платы за API

Подходит, если облачный сервис недоступен или не хочется создавать аккаунт. Вычисления выполняются на вашем компьютере, скорость и качество зависят от модели и оборудования.

1. В мастере выберите `1`.
2. Если Ollama не установлена, мастер откроет https://ollama.com/download/windows . Скачайте установщик с официального сайта, установите и запустите Ollama.
3. Ещё раз запустите `connect-ai.bat` → `1`.
4. Для модели нажмите Enter: используется `qwen3:8b`. Файл модели около 5.2 ГБ, кроме него нужны место под Ollama и память для работы. Для учебного курса желательно 16+ ГБ ОЗУ; на CPU генерация может идти несколько минут. Это ориентир, а не гарантия скорости.
5. Мастер при необходимости выполнит скачивание модели через `ollama pull`, покажет прогресс и проверит короткую JSON-генерацию. Суффиксы cloud не используются: выбран локальный режим.
6. После успешной проверки настройки сохранятся. Запустите обычный `start.bat` в папке вашего проекта.
7. В интерфейсе появится «Локальная AI · Ollama».

Ollama по умолчанию доступна на http://127.0.0.1:11434 . Ключ локальному API не нужен. Мастер не открывает этот порт в интернет. После установки и скачивания модели интернет для генерации не нужен. Оплата электричества и использование ресурсов компьютера остаются.

Не выбирайте крупную модель наугад. Для слабого компьютера сначала проверьте курс из двух вопросов. Если урок не успевает сформироваться, сократите материал или выберите облачный вариант. Генератор и проверяющий работают последовательно, каждый требует отдельного вычисления. Даже если короткая проверка JSON прошла, это не гарантирует качество или скорость большого курса.

## Вариант 2: Gemini — бесплатный облачный тариф с квотами

Google публикует Free Tier для определённых моделей, включая Gemini Flash на момент подготовки этой сборки. Доступ зависит от региона и аккаунта. Россия не указана в текущем списке доступных регионов. В таком случае используйте локальную Ollama. Квоты меняются; бесплатный доступ не означает неограниченную генерацию.

1. В мастере выберите `2`. Откроется https://aistudio.google.com/apikey .
2. Войдите в свой Google-аккаунт. Если нужно, примите условия сервиса.
3. Нажмите Create API key / «Создать API-ключ». Выберите свой проект или создайте новый. У нового пользователя Google может уже создать проект и ключ.
4. Используйте проект **Free Tier**. Не включайте Billing / платный тариф ради этой инструкции и не вводите банковскую карту.
5. Скопируйте свой ключ и вставьте его **в окно мастера**, не в чат. Ввод скрыт: это нормально. Нажмите Enter.
6. Для модели нажмите Enter. По умолчанию используется `gemini-3.8-flash`. Если модель изменится, укажите доступную вашему аккаунту модель с Free Tier; список и тарифы смотрите в официальной документации.
7. Мастер проверит короткий запрос без ваших документов. Только после правильного ответа он сохранит ключ в локальном `.env`.
8. Запустите `start.bat`. Вверху приложения появится «Gemini AI».

Мастер не может определить тариф проекта по одному ключу. Если вы используете ключ проекта с уже подключённой оплатой, запросы могут тарифицироваться. Приложение само не оформляет подписки, не подключает Billing и не переключается на платную модель. При исчерпании квоты оно показывает ошибку. Бесплатный тариф Google может использовать запросы и ответы для улучшения продуктов: не отправляйте конфиденциальные материалы.

## Что включится

CourseAgent создаёт план, объяснения и задания по найденным фрагментам. ReviewerAgent отдельным вызовом той же модели проверяет результат. До трёх версий результата: первая генерация и два исправления. Проверка открытого ответа также проходит генератор и проверяющий. Программные проверки источников, структуры и бюджета сохраняются. Код ученика не запускается.

Проверка мастера подтверждает ответ выбранной модели, а не прохождение всех сценариев курса. Для полной проверки создайте новый курс с двумя вопросами по HTML, постройте план, откройте тему, подготовьте урок и отправьте открытый ответ. В «Журнале AI» посмотрите модель и результаты проверок.

Старые демоуроки не заменяются автоматически. Для них: Настройки курса → Создать исправленную копию курса → проверить вопросы → построить план и уроки заново.

## Ручные настройки, если мастер не нужен

Ollama:

```env
AI_MODE=ollama
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3:8b
```

Gemini:

```env
AI_MODE=gemini
GEMINI_API_KEY=ваш_собственный_секретный_ключ
GEMINI_MODEL=gemini-3.8-flash
```

Заменяйте соответствующие строки .env без дублирования. Ключ хранится на сервере и не выдаётся в `/api/config`. Перезапуск сервера обязателен. `/api/config` показывает наличие настроек, но не проверяет связь с провайдером.


## Ошибки

- Мастер просит остановить сервер: Ctrl+C в старом окне сервера, затем повторить мастер.
- Gemini 401/403: неверный ключ, недостаточные права или регион не поддерживается.
- Gemini 429: квота или частота запросов исчерпана; повторить позже. Приложение не покупает дополнительные запросы.
- Модель не найдена: проверить имя; для Ollama скачать модель через мастер.
- Нет ответа Ollama: запустить Ollama, проверить память, сократить тему.
- JSON не прошёл проверку: модель не смогла выполнить формат; настройки мастера сохраняются только после успешной проверки.

Существующие настройки `.env` резервируются в `.env.backup-...`; эти файлы тоже содержат секреты и не должны попадать в публичные архивы. Мастер не удаляет ключи других провайдеров, чтобы можно было переключиться обратно.
