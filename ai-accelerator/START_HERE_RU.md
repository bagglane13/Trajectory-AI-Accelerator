# Запуск полного комплекта 1.3.6

Актуальный запуск: **START.bat в общей папке уровнем выше**. Исходники приложения находятся здесь, в ai-accelerator; отдельные архивы не нужны.

Подробности: [README общего проекта](../README.md) и Word-инструкция `../Trajectory_AI_Instruction_RU.docx`.

Приложение использует локальную qwen3:8b через Ollama. Зависимости и модель скачиваются при первом запуске. Все локальные файлы остаются внутри общей папки; рабочая база — `data`, движок и модель — `../.runtime`.
