1. ПЕРЕМЕННЫЕ И ТИПЫ ДАННЫХ

Переменная в Python — это имя, связанное с объектом. Оператор присваивания = связывает имя с результатом выражения справа. Например, age = 18 создает привязку имени age к целому числу 18. Повторное присваивание может связать это имя с другим объектом. Нельзя путать присваивание = и сравнение ==.

Основные типы: int для целых чисел, float для чисел с плавающей точкой, str для строк и bool для логических значений True и False. Функция type() позволяет узнать тип объекта. Для явного преобразования применяются int(), float() и str(). Преобразование int("abc") завершится ошибкой, так как строка не содержит целого числа.

Пример:
name = "Артём"
age = 18
print(name, age)

Функция print() выводит значения на экран. Функция input() читает строку. Чтобы использовать введенное число в арифметике, обычно требуется преобразование: count = int(input()). Ввод должен быть корректным; обработка исключений изучается отдельно.

Тип int поддерживает сложение +, вычитание -, умножение *, деление /, целочисленное деление //, остаток % и возведение в степень **. Обычное деление 5 / 2 дает 2.5, а 5 // 2 дает 2. Строки можно объединять оператором +. Выражение "2" + "3" дает "23", а не 5.

Для ответа на экзамене объясните, чем имя отличается от значения, перечислите базовые типы и приведите пример ввода числа. При чтении кода последовательно отслеживайте изменение привязок имен после каждой строки.

2. УСЛОВИЯ И ЛОГИЧЕСКИЕ ВЫРАЖЕНИЯ

Условный оператор if выполняет блок, когда условие истинно. elif проверяет следующее условие, если предыдущие оказались ложными. else выполняется, если ни одна предыдущая ветвь не выбрана. В одной цепочке if/elif/else выполняется не более одной ветви.

Пример:
age = 18
if age >= 18:
    print("Совершеннолетний")
else:
    print("Несовершеннолетний")

После условия ставится двоеточие. Вложенный блок выделяется отступом, обычно четырьмя пробелами. Смешивание табуляции и пробелов может привести к ошибке. Операторы сравнения: ==, !=, <, >, <=, >=. Значением сравнения является логическое значение.

Логическое and соответствует совместному выполнению условий, or — выполнению хотя бы одного, not — отрицанию. Для явного указания порядка сложные условия заключают в скобки. Python использует короткое замыкание: правый операнд and/or может не вычисляться. Это позволяет написать x != 0 and 10 / x > 1 без деления на ноль при x, равном нулю.

Пустая строка, пустой список, ноль и None при проверке условия считаются ложными. Непустые строки обычно истинны: строка "False" сама по себе не равна логическому False.

Практика: определите вывод условного оператора при трех разных значениях переменной. Для экзамена объясните разницу между отдельными if и одной цепочкой if/elif/else. Покажите пример логического выражения для проверки попадания числа в интервал.

3. ЦИКЛЫ FOR И WHILE

Цикл for последовательно перебирает элементы итерируемого объекта. Для перебора целых чисел часто используется range(). Вызов range(3) задает 0, 1, 2; правая граница не включается. Вызов range(1, 5) задает 1, 2, 3, 4. Третий аргумент задает шаг: range(2, 7, 2) задает 2, 4, 6.

Пример суммы:
total = 0
for number in range(1, 4):
    total += number
print(total)

Здесь выводится 6. Начальное значение аккумулятора задают до цикла. Если обнулять total внутри цикла, предыдущая сумма потеряется.

Цикл while повторяет блок, пока условие истинно. Условие проверяется до каждой итерации, поэтому тело может не выполниться ни разу. Необходимо обеспечить изменение данных, влияющих на условие, или предусмотренный выход.

count = 3
while count > 0:
    print(count)
    count -= 1

Этот пример выводит 3, 2, 1. Если убрать уменьшение count, цикл станет бесконечным. Оператор break завершает ближайший цикл, continue переходит к следующей итерации. Во вложенных циклах break не завершает сразу все уровни.

Для ответа на экзамене сравните for и while, объясните диапазон range и продемонстрируйте условие завершения. При трассировке записывайте значение переменной на каждом шаге, особенно проверку границы и изменение счетчика.

4. ФУНКЦИИ

Функция — именованный фрагмент программы, который можно вызывать. В Python определение начинается с def, затем указываются имя и параметры в скобках. Тело функции выполняется при вызове, а не при чтении определения.

def square(number):
    return number * number

result = square(4)
print(result)

Параметр number получает переданный аргумент 4; функция возвращает 16. Параметры — имена в определении функции, аргументы — значения или выражения в вызове. Оператор return завершает текущий вызов и передает значение вызывающему коду. Если явного return со значением нет, функция возвращает None.

print() и return решают разные задачи. print() выводит текст, а return позволяет использовать результат в дальнейшем вычислении. Функция, которая только печатает число, не возвращает это число автоматически.

Переменные, присвоенные внутри функции, обычно локальны этому вызову. Одноименное имя за пределами функции не обязано измениться. Для простых функций желательно передавать необходимые данные через параметры и возвращать результат, не полагаясь на изменение глобальных переменных.

Можно задавать значения параметров по умолчанию: def greet(name="Гость"). Если аргумент не передан, используется значение по умолчанию. Изменяемые объекты как значения по умолчанию требуют осторожности: они создаются при выполнении определения функции, а не заново для каждого вызова.

Для экзамена дайте определение функции, различите параметр и аргумент, объясните возвращаемое значение и локальную переменную. Практика: напишите функцию, которая принимает два числа и возвращает большее, затем объясните работу каждой ветви.
