# Trajectory AI

Локальный веб-акселератор для подготовки к экзамену по программированию. Методичка, контрольные вопросы, уровень знаний и расписание превращаются в дорожную карту, уроки с практикой и итоговый тест по слабым темам. Код в заданиях анализируется без выполнения.

## Проверка преподавателем с нуля

Начните с **PREPOD_START_HERE.txt**: требования, первый запуск, примеры материалов, проверка уроков, оценивания, прогресса и журнала агентов. Для короткого курса в `ai-accelerator/examples/` добавлен `teacher-questions.txt` с двумя вопросами к существующей примерной методичке. Код приложения — 1.3.6; это сборка для проверки с описанными ограничениями качества AI.

## Обновление установленного проекта до 1.3.6

Для нового компьютера распакуйте ZIP в пустую папку. Для уже установленной копии следуйте **UPDATE_1_3_6_RU.txt**: остановите серверы, переместите старую подпапку приложения в резервную папку вне проекта, распакуйте чистые исходники и верните `data`, `.venv` и `.env` на прежние пути. Корневую `.runtime` с моделью оставьте на месте. Так устаревшие файлы не попадут в действующее приложение, а курсы и модель сохранятся. Простое объединение папок не удаляет старые файлы.

Версия 1.3.6 содержит один способ оркестрации — встроенную очередь на Python — и хранит данные в SQLite. Сохранены RAG по методичке, генерация, проверяющий агент, цикл исправлений и адаптивный итоговый тест. Формат пользовательской базы не менялся.

## Запуск на Windows

1. Распакуйте **весь** архив в обычную папку с правом записи.
2. Откройте `START.bat` в корне распакованного проекта.
3. Дождитесь сообщения `ГОТОВО` и открытия браузера. Оставьте окно сервера открытым.

Все исходники уже находятся в этом архиве. Второй архив или отдельный BAT скачивать не требуется. При первом запуске скрипт автоматически скачивает системные зависимости и модель из официальных источников. Интернет нужен для подготовки; API-ключ и аккаунт облачного AI не нужны.

Подробная инструкция: **Trajectory_AI_Instruction_RU.docx** рядом с START.bat. Быстрая памятка: **README_START.txt**.

Требования: Windows 10 22H2/11 x64, минимум 12 ГБ ОЗУ (желательно 16 ГБ), около 15 ГБ свободного места **на диске с проектом**. Первичная загрузка — около 7 ГБ плюс Python и библиотеки. Модель `qwen3:8b` работает через приватный portable Ollama. Установленная отдельно Ollama и настройки ChatGPT не изменяются.

## Состав

- `START.bat`, `START.ps1`, `run_local.py` — запуск и автоматическая подготовка.
- `ai-accelerator/frontend/` — HTML, CSS, JavaScript.
- `ai-accelerator/app/` — FastAPI, агенты, RAG, календарь, задания и итоговый тест.
- `ai-accelerator/tests/` — автоматические проверки.
- `ai-accelerator/examples/` — небольшие открытые примеры методички и вопросов.
- `scripts/build_release.py` — сборка такого же чистого ZIP из исходников.

Версия комплекта: **1.3.6**. START.bat запускает именно соседнюю папку `ai-accelerator`. Исходники не копируются в старый проект или AppData и не перезаписываются при повторном запуске.

## Проверка локальной модели при запуске

На шаге 5 запускатор отправляет короткий запрос со строгой JSON-схемой. При некорректном ответе выполняется ещё одна попытка. Результат и причины ошибки сохраняются в `.runtime/logs/startup-ai.json`; после двух отказов сайт не запускается. Повторная установка весов для исправления ошибки формата ответа не нужна.

## Данные и модель

После первого запуска создаются:

- `ai-accelerator/data/` — база SQLite, курсы, прогресс и загруженные документы.
- `ai-accelerator/.env` — локальные настройки подключения.
- `ai-accelerator/.venv/` — Python-библиотеки.
- `.runtime/` — скачанные Python/Ollama, модель, журналы и служебные файлы запуска.

Всё находится внутри общей папки проекта. Журналы: `.runtime/logs/app.log` и `.runtime/logs/ollama.log`. Сервер сайта использует свободный порт 8000–8019, приватный Ollama — 11435–11454. Фактические адреса видны в окне запуска. Порт обычной Ollama 11434 не перенастраивается.

При новом распаковывании курс начинается с пустой базы. Для переноса прежних курсов сначала остановите оба сервера и скопируйте **всю** папку `data` прежнего приложения в `ai-accelerator/data`. Сохраните исходную копию до проверки. Настройки SQLite и локальной AI запускатор задаёт автоматически.

## Разработка и проверки

Откройте общую папку в VS Code. CSS/JS меняются в `ai-accelerator/frontend`; после изменения обновите браузер через Ctrl+F5. После изменения Python остановите сайт и снова откройте START.bat. Правки сохранятся.

Автоматические проверки после установки зависимостей, из корня проекта в Windows:

```bat
ai-accelerator\.venv\Scripts\python.exe -m pytest -q
```

На Linux для серверных тестов установите `ai-accelerator/requirements.txt` в отдельное окружение и выполните `python -m pytest -q` из корня. Windows BAT/PowerShell при этом не проверяются. Отчёт о выполненной проверке — `TESTING.md`.

Пересборка архива в Windows:

```bat
ai-accelerator\.venv\Scripts\python.exe scripts\build_release.py
```

Архив появится в `dist/`. Модели, базы, пароли, виртуальное окружение и личные методички в него не включаются.


## Несколько методичек

Форма курса принимает до 40 файлов PDF, DOCX или TXT за один выбор. Файлы загружаются последовательно, сохраняются отдельными документами и вместе участвуют в RAG-поиске. В ссылках на источники сохраняется имя исходной методички. Серверный предел — 50 документов на курс с учётом отдельного файла вопросов.
